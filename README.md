# Brampton FBLC (Future Business Leaders Club)

Official modern web application for Brampton Future Business Leaders Club — Canada's premier youth-led business organization.

## 🚀 Features
- **Multi-Page Architecture**: Full suite of dedicated pages for About, Founder, Programs (Academics, Governance, Technology), Events, Team, Join Us, and Contact.
- **Executive Aesthetics**: Dark luxury cyber & executive navy palette with custom inline SVG iconography and zero emojis.
- **Ultra-Smooth Animation Engine**: 60–120 FPS hardware-accelerated particle canvas constellation, parallax depth, and scroll reveals.
- **Infinite Looping Circle Ticker**: Seamless metrics marquee on the homepage.
- **Google Forms Integration**: One-click direct link to official General Member Application.

## 🌐 Deploy to GitHub Pages
1. Go to your repository settings on GitHub.
2. Under **Pages**, select **Deploy from a branch** -> branch: `main`, folder: `/ (root)`.
3. Click **Save** — your website will be live at `https://<your-username>.github.io/<repo-name>/`.
